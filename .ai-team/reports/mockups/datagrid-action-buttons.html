DataGrid Action Buttons: Before & After

Action buttons in MudDataGrid cells currently use Bootstrap button classes with open-iconic icons. This mockup shows the improved version using MudIconButton with Material Icons.

❌ BEFORE: Bootstrap + open-iconic
Animation Name Enabled Actions
!cheer100 Yes
!raid Yes
!dance No
Issues
  • Square buttons feel dated (Bootstrap 4 style)
  • open-iconic icons are low-res and inconsistent
  • No hover color feedback on icons
  • Missing aria-label for accessibility
  • Inline style for width/height
✅ AFTER: MudIconButton + Material Icons
Animation Name Enabled Actions
!cheer100 Yes
!raid Yes
!dance No
Improvements
  • Circular buttons follow Material Design 3
  • Crisp Material Icons at any size
  • Color feedback on hover (edit=purple, delete=red, play=green)
  • Built-in aria-label for screen readers
  • Focus ring for keyboard navigation
  • Subtle scale transform on hover
<!-- Recommended Razor implementation for TemplateColumn --> <TemplateColumn Title="Actions"> <CellTemplate Context="itemcontext"> <MudStack Row="true" Spacing="1"> <MudIconButton Icon="@Icons.Material.Filled.Edit" Size="Size.Small" Title="Edit" aria-label="Edit animation" OnClick="@(() => HandleEdit(itemcontext.Item))" /> <MudIconButton Icon="@Icons.Material.Filled.Delete" Size="Size.Small" Color="Color.Error" Title="Delete" aria-label="Delete animation" OnClick="@(() => HandleDelete(itemcontext.Item))" /> <MudIconButton Icon="@Icons.Material.Filled.PlayArrow" Size="Size.Small" Color="Color.Success" Title="Play" aria-label="Play animation" OnClick="@(() => HandlePlay(itemcontext.Item))" /> </MudStack> </CellTemplate> </TemplateColumn>
