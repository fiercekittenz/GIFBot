### 2026-02-15: Regurgitator package management UX improvements
**By:** Helly
**What:** Three fixes to the Regurgitator page: (1) Fixed empty GUID appearing in package dropdown by adding `ToStringFunc` to MudSelect that returns empty string for `Guid.Empty`, enabling proper placeholder display. (2) Replaced hardcoded package name with an inline MudDialog prompt matching the Settings.razor "Add New Group" dialog pattern — includes validation for empty/duplicate names. (3) Moved Delete Package button from the toolbar to the bottom-left of the form area, separated from Cancel/Save on the right via `d-flex justify-space-between`.
**Why:** The empty GUID was confusing users into thinking a package existed when none did. The Add button creating packages with a hardcoded name ("New Package") was a leftover TODO from the Telerik migration. The Delete button placement follows the established pattern of keeping destructive actions visually separated from constructive ones (Cancel/Save).
